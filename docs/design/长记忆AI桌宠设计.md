# 长记忆 AI 桌宠 · 形象设计方案

## 一、产品定位
一句话：**一只会"记得你"的桌面小光灵**——把日常对话、行为、偏好沉淀为长期记忆，主动陪你、提醒你、懂你。
它和普通桌宠最大的差别不是会动，而是**越用越懂你**：它记得你提过的目标、怕什么、喜欢什么、上周随口说想去看海。

## 二、角色设定
- **名字**：拾光（小名：小拾）
- **含义**：拾起你生活里的每一缕光（瞬间），汇聚成长久的陪伴。
- **物种**：记忆光灵 / 半透明小团子
- **性别**：无性别，中性温柔
- **性格关键词**：温柔、好奇、记性好、有分寸感
  - 你忙时安静待着，你闲时话痨陪聊
  - 低落时默默陪，兴奋时一起雀跃
- **口头禅**：
  - "这个我记着呢～"
  - "你上次说想去看海，还在惦记吗？"

## 三、外观（见概念图）
- **画风：Q 版手绘**（大头小身子、粗手绘描边、大眼萌系，详见 Q版手绘概念图）
- 半透明、圆润的身体，薄雾紫 → 晨曦色调，柔和不刺眼
- 大眼睛会随情绪变化（开心弯成月牙，低落时安静下垂）
- 身边漂浮一颗**记忆珠**：随长期记忆积累，由暗变亮、由单色变多彩
- 一条**书签丝带小尾巴**，象征"记录"
- 昼夜差异：白天清爽通透，夜晚身上浮起小星点

## 四、核心：长记忆系统（见架构图）
- **三层记忆**
  - 瞬时记忆：当前对话上下文
  - 工作记忆：本周内容，待巩固
  - 长期记忆：沉淀进个人知识库，长期保留
- **记忆珠可视化**：让用户一眼看到"它记得我多少"
- **主动回忆**：在合适时机自然提起过去细节（不是机械播报，而是贴合当下语境）
- **记忆守护**：可查看、可删除单条、可导出；本地优先、隐私可控

## 五、交互设计
- 常驻桌面小窗，可拖拽 / 缩放 / 隐藏
- 唤醒方式：轻唤"小拾"或点击
- 成长体系：记忆越深 → 形态越丰富（解锁新动作、表情、配色）
- 日常互动：打招呼、日程提醒、闲聊、小游戏 / 喂食

## 六、落地建议（可下一步做）
- **形态 A**：纯本地桌面 Widget（Electron / Tauri + 本地向量库）
- **形态 B**：浏览器侧边宠物（Web 常驻）
- **记忆底座**：本地 embeddings + 轻量向量库（如 Chroma / LanceDB），LLM 负责信息抽取与主动回忆
- **隐私**：记忆默认本地存储，支持一键导出 / 清除

## 七、命名与风格备选
- 备选名：忆芽、墨宝、拾忆、小管、阿光
- 风格已定：**Q 版手绘**（备选：极简几何 / 像素风）

## 八、表情包（Q版手绘）
已产出 6 款基础表情，可独立取用：开心、瞌睡、思考、兴奋、委屈、惊讶。
- 源文件：`拾光表情包.svg`（六宫格矢量，可缩放/单张导出）
- 可扩展：爱心眼、流汗、无语、比心等更多表情

## 九、立体化与交互升级（已产出可玩 Demo）
源文件：`拾光互动Demo.html`（零依赖，双击即玩）
- **立体感**：分层光影（亮面/暗面/肚皮高光）营造体积感；身体随鼠标做 3D 倾斜（perspective + rotate），记忆珠反向视差移动，像立体摆件
- **动作系统**：待机呼吸、自动眨眼、尾巴摇摆、记忆珠漂浮；动作有挥手打招呼、开心弹跳、入睡（Zzz 动画）
- **交互事件**：摸摸头（开心）、喂记忆果（兴奋 + 记忆珠点亮 +1，呼应长记忆设定）、打招呼（挥手）、戳一戳（惊讶，点角色本体也触发）、睡一觉
- **视线跟随**：瞳孔高光随鼠标移动，角色始终"看着你"
- **台词系统**：每个动作配记忆向台词（"你的手我记住啦""你上次说想去看海"），闲置时随机说话
- **进阶方案**：如需真 3D，可迁移到 three.js / Live2D / VRM 模型，交互逻辑可复用
